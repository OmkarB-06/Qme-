ABOUT THE PROJECT

Question Me — Aptitude Test Platform

Question Me turns aptitude preparation into a game. Instead of grinding through static question papers, students climb a 20-level trail — each level a fresh 15-question, 15-minute test and from 21-level 30 questions,30 minutes that blends quantitative aptitude, logical reasoning, and real-world coding questions in C++, Java, and Python.

01

What is Question Me?

Question Me is a self-paced, game-style aptitude testing platform built for students preparing for placement drives, entrance exams, and technical interviews. Rather than one long, generic test, the platform breaks preparation into progressively harder levels — like stages in a game — so students build confidence step by step instead of being overwhelmed on day one.

🧩

Game Levels

Each level unlocks only after the previous one is cleared, so difficulty rises naturally from beginner to placement-ready.

⏱️

1 Question · 1 Minute

Every level is a timed test — 1 question in 1 minute — mirroring the pace of real aptitude exams.

🧠

Quant + Logical + Coding

Questions span numerical aptitude, logical & relationship reasoning, and real-world coding problems in C++, Java, and Python.

📊

Instant Scoring

Correct, incorrect, and unattempted counts are calculated the moment a test is submitted, along with marks, percentage, and grade.

📅

Progress Calendar

Every attempt is logged on a calendar, so students and mentors can see exactly which days tests were taken and how they went.

🏆

Grades & Streaks

Performance is converted into simple grades (A+ to F), making it easy to track improvement over time.

02

How the Project Runs

Question Me is built entirely with HTML, CSS, and JavaScript — no server, database, or backend framework is required to use it. The whole platform runs directly in the browser.

1

Open the app

The student opens in any modern browser (Chrome, Edge, Firefox). No installation or account setup is needed to start.

2

Pick a level

Start a level, the student selects the current unlocked level and starts the test.

3

Answer & submit

Questions are answered one at a time with a question-jump grid to review or change answers before the timer runs out.

4

Get instant results

On submission, the app calculates correct/incorrect/unattempted counts, marks, percentage, and grade, then unlocks the next level if the score qualifies.

5

Track progress

Every attempt is saved and shown on the Dashboard and Calendar pages, so progress over days and weeks is always visible.

Benefits of This Project

✓

Structured, gradual learning

The level-by-level format prevents students from jumping into hard questions too early, building both skill and confidence.

✓

Covers real placement topics

Combines the three areas most Indian campus placement tests actually check: quantitative aptitude, logical reasoning, and programming fundamentals.

✓

Exam-like time pressure

The 30-minute timer trains students to manage time under pressure, just like a real test.

✓

Self-tracked improvement

The Dashboard and Calendar give a clear, honest picture of consistency and improvement — no manual score-keeping needed.

✓

No cost, no installation

Runs fully offline in a browser with no sign-up, no server, and no dependency on an internet connection once downloaded.

✓

Motivating, game-like design

Levels, stars, and unlocks make repeated practice feel like progress in a game rather than a chore.
